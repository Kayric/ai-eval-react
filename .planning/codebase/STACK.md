# Tech Stack

The project is a modern React web application built for high performance and interactive data visualization.

## Core Frameworks
- **React 19.2.4**: The latest version of React, utilizing the new features and improved performance.
- **Vite 6.4.1**: A fast build tool and development server for modern web projects.
- **TypeScript 5.9.3**: Used for static type checking and improved developer experience.

## Styling & UI
- **Tailwind CSS 4.2.1**: A utility-first CSS framework for rapid UI development, configured with the new `@tailwindcss/vite` plugin.
- **Framer Motion 12.36.0**: A library for creating smooth animations and transitions.
- **Phosphor Icons (@phosphor-icons/react) 2.1.10**: A flexible icon family used throughout the application.

## Data Visualization
- **Chart.js 4.5.1**: A powerful library for creating flexible and interactive charts.
- **react-chartjs-2 5.3.1**: React wrapper for Chart.js.

## Routing
- **React Router DOM 7.13.1**: Handles client-side routing and navigation.

## Development Tools
- **ESLint 9.39.4**: For code linting and maintaining code quality.
- **PostCSS 8.5.8 & Autoprefixer 10.4.27**: For CSS transformation and cross-browser compatibility.
